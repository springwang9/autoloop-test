# autoloop-test

A simple Python calculator used to test the OpenFusion PR auto-loop system.

## Functions

- `add(a, b)` — addition
- `subtract(a, b)` — subtraction
- `multiply(a, b)` — multiplication
- `divide(a, b)` — division
- `power(base, exp)` — exponentiation
- `average(numbers)` — mean of a list
- `factorial(n)` — factorial of n

## Run tests

```bash
pip install pytest
pytest test_calculator.py -v
```
